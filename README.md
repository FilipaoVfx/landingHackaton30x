# Secura — Hackathon 30x

Landing page del proyecto **Secura**, presentado en el Hackathon 30x.  
Secura convierte cada conversación en una experiencia de protección inteligente. Escucha, entiende y acompaña la decisión, las 24 horas, por voz y por chat.

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4 + shadcn/ui
- Radix UI + Motion (Framer Motion)

## Desarrollo

```bash
npm install
npm run dev
```

## Build & deploy (Cloudflare Pages)

```bash
npm run build   # genera dist/
```

En Cloudflare Pages:
- **Build command:** `npm install && npm run build`
- **Build output directory:** `dist`
